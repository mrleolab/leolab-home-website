# leolab-home-website

Leo Lab is an original static personal-homepage template with a generated avocado mascot.

## Deploy to Cloudflare Workers

This is a dependency-free static site. From this directory, deploy with:

```sh
npx wrangler deploy --assets .
```

Or use the Cloudflare dashboard to upload this directory as static assets.

## Contents

- `index.html` — the page
- `styles.css` — responsive styles and animation
- `assets/avocado-mascot.png` — original transparent PNG mascot, created with OpenAI image generation
