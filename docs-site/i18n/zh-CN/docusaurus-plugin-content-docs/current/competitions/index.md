这里覆盖 Leo Lab 原菜单中的全部九个官方入口，按美国、加拿大的数学与物理分类；不是全球所有竞赛的完整目录。

**官方资料核对日期：2026 年 10 月 26 日。** 每项日期注明对应届次，往年考试不代表现在仍能报名。本指南不会自动更新。

## 按学科和地区选择

- [数学 · 美国](./math-usa.md)：MAA AMC、MATHCOUNTS。
- [数学 · 加拿大](./math-canada.md)：滑铁卢 CEMC、Euclid、COMC。
- [物理 · 美国](./physics-usa.md)：F=ma / USAPhO、PhysicsBowl。
- [物理 · 加拿大](./physics-canada.md)：CAP 物理竞赛、牛顿物理竞赛。

## 报名前检查

1. 核对年级、年龄、考试地点与国籍或居留要求；初赛和国家队选拔的资格可能不同。
2. 先问学校是否承办，校内截止日期可能比主办方更早。
3. 在各页官方链接确认当届日期、时区、费用、允许使用的设备与监考要求。
4. 用官方往年试题判断难度；报名培训班不等于已经报名竞赛。

:::note 给加拿大家庭的提示
美国机构举办的竞赛不一定允许学生在加拿大考试。特别是 F=ma 与 USAPhO，安排前务必阅读考试地点及资格限制。
:::
