建立对 IP 地址、路由、交换、故障排查和网络运维的理解。

## 如何选择路线

Cisco 与 Juniper 提供官方认证路线。把当前报考要求和能力大纲，与自己能使用的设备或虚拟实验环境进行比较。

## 官方认证资源

- [Cisco Certifications](https://www.cisco.com/site/us/en/learn/training-certifications/certifications/index.html)
- [Juniper Certifications](https://www.juniper.net/us/en/training/certification.html)

## 开始实践

练习子网划分、阅读路由表、排查简单连接故障。使用合法模拟器或自己的设备；准备考试不等于获得访问其他网络的许可。

:::note 报名前核对
认证名称、考试版本、费用、资格与续证政策可能变化，以认证机构当前文档为准。课程结业证明或徽章不一定等同于职业认证。
:::
