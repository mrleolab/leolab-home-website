## 从一个目标开始

1. 确定自己想从事的岗位或完成的项目。
2. 选择与之相关的一个平台或技术。
3. 阅读官方考试大纲、报考条件、费用与续证政策。
4. 做一个实践项目，找出不足，再有针对性地准备。
5. 准备好后再报名，付款请自行在认证机构官网完成。

## 这里收录什么

链接指向认证机构，而不是考试题库或“保过”卖家。部分入口为完整目录，方便选择当前有效的认证。培训课程、结业证明、徽章与职业认证不是同一概念，请确认最终获得的资格是什么。

:::caution 费用与资格
这是独立学习资源目录，不是认证机构，也不保证就业。考试、培训或云实验可能收费。要求与可报考认证会变化，付费前请再次核对。不要把个人证明文件或付款信息上传到本网站。
:::
