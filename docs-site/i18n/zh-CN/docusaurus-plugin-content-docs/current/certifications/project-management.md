技术项目同样需要计划、交付、沟通与风险管理。

## 如何选择路线

PMI 官方目录包含入门和高级项目管理方向。选择前核对当前资格、教育背景和工作经验要求。

## 官方认证资源

- [PMI Certifications](https://www.pmi.org/certifications)

## 开始实践

为一个小项目制定范围、里程碑与风险清单，结束后写复盘。职业认证不能代替真实的项目交付经验。

:::note 报名前核对
认证名称、考试版本、费用、资格与续证政策可能变化，以认证机构当前文档为准。课程结业证明或徽章不一定等同于职业认证。
:::
