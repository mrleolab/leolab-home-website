## 如何选择路线

CNCF 发布云原生认证方向；HashiCorp 的目录涵盖其基础设施与安全工具。选择自己有条件实践的路线。

## 官方认证资源

- [CNCF Certifications](https://www.cncf.io/training/certification/)
- [HashiCorp Certifications](https://www.hashicorp.com/en/certification)

## 开始实践

把一个小型基础设施或容器项目纳入版本管理，说明部署、回滚和安全边界。阅读当前考试大纲，不要只依赖旧的考试代码。
