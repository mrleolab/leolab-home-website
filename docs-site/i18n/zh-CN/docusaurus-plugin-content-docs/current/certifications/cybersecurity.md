学习防御性安全知识、风险意识，以及保护系统与网络的实践技能。

## 如何选择路线

ISC2 提供多种认证；Fortinet 和 Palo Alto Networks 有各自面向产品的认证体系。厂商认证与更广泛的职业认证用途不同。

## 官方认证资源

- [ISC2 Certifications](https://www.isc2.org/certifications)
- [Fortinet Certifications](https://www.fortinet.com/training-certification)
- [Palo Alto Networks Certifications](https://www.paloaltonetworks.com/services/education/certification)

## 开始实践

新手先打基础。选择高级认证前，核对工作经验与背书要求。实验只在自己拥有或得到明确授权的系统中进行。

:::note 报名前核对
认证名称、考试版本、费用、资格与续证政策可能变化，以认证机构当前文档为准。课程结业证明或徽章不一定等同于职业认证。
:::
