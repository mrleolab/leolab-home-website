这里是服务器管理与 Linux 职业认证，不是网站 HTTPS/TLS 服务器证书。

## 如何选择路线

Red Hat、Linux Foundation 和 LPI 提供系统管理及相关技能的官方认证路线。

## 官方认证资源

- [Red Hat Certifications](https://www.redhat.com/en/services/certifications)
- [Linux Foundation Certifications](https://training.linuxfoundation.org/certification-catalog/)
- [LPI Certifications](https://www.lpi.org/our-certifications/)

## 开始实践

创建本地 Linux 虚拟机，练习用户、权限、服务、日志、存储与恢复。以认证机构列出的考试环境和目标为准。

:::note 报名前核对
认证名称、考试版本、费用、资格与续证政策可能变化，以认证机构当前文档为准。课程结业证明或徽章不一定等同于职业认证。
:::
