从一个小想法开始，把它发布上线，再让它成为你的作品。

这是 Leo Lab 知识库的第一份教程。沿着建设这个社区网站时采用的工作方式：向 Codex 描述想法，用 GitHub 保存代码，通过 Cloudflare 发布，准备好后再绑定自己的域名。

你不必先精通编程语言，但需要理解修改目的、测试实际结果，并掌握自己账号的控制权。

## 开始前需要什么

- 电脑、浏览器和可以收信的 Gmail。其他邮箱也可以，这里以 Gmail 为例。
- ChatGPT 账号与 Codex 权限；可用功能取决于当前套餐和工作区设置。
- 一个简单的想法，例如个人主页、学习日志或社区资源导航。
- 安全保存账号与恢复信息的方式。

:::tip 从小处开始
第一版可以只有标题、介绍与有用链接。无需数据库、登录系统或 AI API。
:::

## 费用与安全边界

本教程不保证所有服务永久免费或不限量。接受付费选项前确认 Codex 使用权限、Cloudflare 额度和域名续费价格。自定义域名通常需要付费，但并非必需；可以先在 `workers.dev` 上测试。

不要把密码、恢复码、支付信息或访问令牌放进提示词与公开仓库。账号授权由本人确认，使用第三方代码前检查许可证。

## 常见术语

**仓库（Repository）**保存文件与历史。**提交（Commit）**保存一次修改。**分支（Branch）**是独立的工作路线。**PR**用于检查并提议合并修改。**部署（Deploy）**是发布网站版本。**域名（Domain）**是易记的网址。**DNS** 把域名与服务连接起来。
