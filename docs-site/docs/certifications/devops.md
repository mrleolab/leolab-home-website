## Choose a path

CNCF publishes cloud-native certification options. HashiCorp’s catalog covers its infrastructure and security tooling. Choose a track that matches the tools you can practice with.

## A practical first step

Version-control a small infrastructure or container project. Explain the deployment, rollback, and security boundaries. Read the current exam outline instead of relying on an old exam code.

:::note Check before registering
Names, exam versions, fees, eligibility, and renewal policies can change. Follow the provider’s current documentation. A course completion certificate or badge is not necessarily a professional certification.
:::
