title: "Cloud Computing"
---

Learn cloud concepts, compute, storage, networking, identity, and operations. Begin with the platform you actually use rather than collecting similar entry-level credentials from every provider.

## Choose a path

AWS and Google Cloud publish multi-level certification catalogs. Azure Fundamentals is a starting point; Microsoft’s full catalog includes further role-based paths.

## Official certification resources

- [AWS Certifications](https://aws.amazon.com/certification/)
- [Microsoft Azure Fundamentals](https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/)
- [Microsoft Certification Catalog](https://learn.microsoft.com/en-us/credentials/certifications/)
- [Google Cloud Certifications](https://cloud.google.com/learn/certification)

## A practical first step

Deploy a small static website, configure permissions carefully, and learn to monitor usage and delete test resources. Cloud lab activity can incur charges even if the certification guide is free.

:::note Check before registering
Names, exam versions, fees, eligibility, and renewal policies can change. Follow the provider’s current documentation. A course completion certificate or badge is not necessarily a professional certification.
:::
