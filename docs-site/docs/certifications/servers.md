This section covers server administration and Linux professional certifications—not HTTPS/TLS server certificates.

## Choose a path

Red Hat, the Linux Foundation, and LPI provide official certification routes for system administration and related skills.

## Official certification resources

- [Red Hat Certifications](https://www.redhat.com/en/services/certifications)
- [Linux Foundation Certifications](https://training.linuxfoundation.org/certification-catalog/)
- [LPI Certifications](https://www.lpi.org/our-certifications/)

## A practical first step

Create a local Linux virtual machine. Practice users, permissions, services, logs, storage, and recovery. Follow the exact exam environment and objectives listed by the provider.

:::note Check before registering
Names, exam versions, fees, eligibility, and renewal policies can change. Follow the provider’s current documentation. A course completion certificate or badge is not necessarily a professional certification.
:::
