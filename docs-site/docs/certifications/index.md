## Start with one goal

1. Pick a role or project you want to work toward.
2. Choose one provider or technology that matches it.
3. Read the official exam outline, prerequisites, cost, and renewal policy.
4. Build a small practical project, identify gaps, and prepare deliberately.
5. Register only when you are ready; complete purchases yourself on the provider’s official site.

## What this directory includes

Links go to certification providers, not exam-dump sellers. Some links open broad catalogs so you can choose the current qualification. Training courses, completion certificates, badges, and professional certifications are different; check what is actually awarded.

:::caution Costs and eligibility
This is an independent learning directory, not an official provider or a guarantee of employment. Exams, training, or cloud labs may cost money. Requirements and available credentials change; verify them before paying. Do not upload personal documents or payment details to this site.
:::
