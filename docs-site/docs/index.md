Build something small. Put it online. Make it yours.

This is the first guide in the Leo Lab Knowledge Base. It follows the same kind of workflow used to build this community website: describe an idea to Codex, keep the code in GitHub, publish with Cloudflare, and connect a domain when you are ready.

You do not need to know a programming language to begin. You do need to read what changes, test the result, and keep control of your accounts.

## Your route from zero

**Gmail → ChatGPT / Codex → GitHub → Cloudflare → Your own domain**

## Before you start

- An Apple Mac computer running macOS. This guide follows a Mac-based workflow.
- A browser and a Gmail address you can access. Another email provider also works; Gmail is simply the example here.
- Access to Codex through your ChatGPT account. Availability depends on your current plan and workspace settings.
- A simple idea: a personal homepage, a learning journal, or a community resource hub.
- A way to record your account names and recovery details securely.

:::tip Start small
Your first version can be one page with a title, a short introduction, and a few useful links. A database, login system, and AI API are not required.
:::

## Costs and boundaries

This guide does not promise that every service is free or unlimited. Check current Codex access, Cloudflare plan limits, and domain renewal prices before accepting paid options. A custom domain is optional and normally costs money; you can test the website on `workers.dev` first.

Never paste passwords, recovery codes, payment details, or access tokens into a prompt or a public repository. Approve account authorizations yourself. Read third-party code licenses before copying code.

## A few words you will see

**Repository:** the project folder and its history on GitHub. **Commit:** a saved set of changes. **Branch:** a separate line of work. **Pull request (PR):** a proposal to review and merge changes. **Deploy:** publish a version of the site. **Domain:** your readable address. **DNS:** the records that connect that address to services.
